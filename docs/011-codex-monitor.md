# 011 本机 Codex 对话监控

Superagent 可以在同一台 Mac、同一 OS 用户下自动观察 Codex 已持久化的对话，并集中汇报变化。历史监控本身不发送消息或中断线程；可另行开启会话控制。审批设置由用户保留。

## 启用

按 [部署说明](006-deployment.md)运行 DSH Superagent 后，在面板的 **Codex 观察** 中点 **开始监控**。监控开关保存在 Superagent 的本机数据库中，服务重启后继续生效。**暂停监控** 停止后续扫描，保留已记录的观察和提醒。无需保持 [本机手动试验](009-codex-read-only.md) 的 GUI 开着。

首次扫描建立游标，并为最近七天有活动的主会话生成简短进展摘要；旧消息不会被当作新的待办。之后约每 30 秒扫描一次，主会话有变化时更新摘要、完成报告或需要人工处理的提醒。最近 24 小时有活动的子智能体线程会分批读取最新的持久化 turn 状态，每轮最多核对 60 条，并把失败数量归到父会话；无父会话的失败单独计数。已读到的子线程状态会留在历史记录中，读取异常另行计数。不读取子线程正文，不单独调用模型、提醒人或派工。面板默认显示最近七天的主会话，**查看全部** 可浏览更早及归档的主会话。需要处理的对话显示在 **概览** 和 **Codex 观察**；侧边栏 Superagent 图标会为未处理提醒显示圆点。**关闭提醒** 只改变 Superagent 面板记录。

子线程没有记录父会话 ID，或其父会话不在本机清单时，面板分别计数。Superagent 不根据时间、标题或正文猜测父子关系。

模型归纳失败时显示异常并在约五分钟后重试；如果主会话先有新活动，则立即重试。依据不在最新助手消息中的提醒不会展示。

“待你处理”只列当前明确要求人工审批、补充必要业务信息或亲自操作的请求。已确认事实、无需确认的说明和引用内容不作为新请求；先查日志还是等 CI、补什么验证等常规选择标为 **DSH 待处理**，交给主 Session 在原授权内推进。分类规则更新后会重新评估最近记录；旧请求的证据已不在可见历史时，DSH 先核实，不向用户照搬过期提醒，控制门禁仍保持。

用户明确要求暂停的会话保持暂停。询问进展和 DSH 自动协调消息不会解除暂停；用户主动明确恢复后才继续。

## 自动接单

自动接单默认关闭。开启监控后，可在 **Codex 观察** 中点 **开启自动接单**；开关保存在 Superagent 的本机数据库中。开启前已经存在的失败记录只作为历史基线，不会补接。

开启后，新近出现、带最新助手消息原文证据且增量读取完整的失败或技术阻塞可成为 DSH 主 Session 的路由候选。接入前核对 Desktop 实时状态，运行中、待审批或状态不明时暂缓；监控器不直接创建 Ticket。助手消息后面的工具记录不会替换派工证据。若最新助手消息同时请求用户批准、答复或决定，即使模型判成失败或技术阻塞，也会归入人工提醒，不会自动接单。子线程、归档线程、普通提醒、只有失败状态而无助手证据的记录同样不会自动接单。同一主会话的同一项只处理一次；派工失败会在面板显示，约五分钟后允许重试。

主 Session 决定创建的 Ticket 集中显示在 **已交给 DSH**，重要结果自动回到 DSH 的 **汇报**。Ticket 的状态来自 DSH 当前记录；Codex 会话摘要仍是历史快照。自动接单与原会话控制使用独立开关。关闭自动接单停止后续候选及其旧授权，不停止已创建的 Ticket；暂停监控同时停止扫描和后续接单。

当本机 Codex 索引记录的 GitHub 仓库与已配置的某个绑定一致时，Ticket 使用该绑定的账号，在自己的目录克隆对应仓库。没有仓库信息或仓库未绑定时，Ticket 进入空目录做诊断，不克隆默认仓库；工作环境提供的 `gh` 和 `git` 命令会拒绝使用默认 GitHub 账号。运行中的仓库工单会锁住其绑定的仓库与 CLI 配置，直到工单结束。

发现线程时只读枚举本机 Codex 会话日志文件，并与本机状态数据库的标题、来源和更新时间关联；对索引缺失的文件只检查有界的首条元信息，排除文件名 ID 与真实会话 ID 不符的重复文件，不读取日志对话正文或修复 Codex 的索引。内容读取只调用 Codex CLI 的 thread/turns/list 和 thread/items/list 只读 RPC。文件已失效、来源无法识别的记录会计入覆盖信息，不伪装成已归纳的主会话；不持久化的临时线程无法枚举。若增量窗口超过读取上限或游标丢失，面板先标记历史缺口，再用最新有界记录重新建立基线；缺口期间的记录不会自动派工，之后的新变化继续监控。

## 状态与数据边界

独立启动的 App Server 读取的是**已存储历史**。面板的“最近进展”“报告完成”“报告受阻”是对可见消息的归纳，不能证明 Codex Desktop 此刻正在运行或等待审批；本功能不提供实时状态。模型分析只接收有界的主会话用户与助手文本，不接收子线程正文、reasoning、命令输出或文件正文。模型可见的提示和回答保存在 Superagent 私有状态数据库中，供核对；面板接口不返回这些正文。

模型结果是提醒建议，可能判断错误。最新主会话结论会更新摘要并撤销不再需要的旧提醒；用户回复也会清除旧的待答提醒。未开启自动接单时，监控不创建 DSH Ticket；开启后也只接符合上述条件的失败或技术阻塞记录，不获得控制 Codex 的权限。
