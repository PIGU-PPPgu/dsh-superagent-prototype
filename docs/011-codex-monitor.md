# 011 本机 Codex 对话监控

Superagent 可以在同一台 Mac、同一 OS 用户下自动观察 Codex 已持久化的对话，并在面板集中显示需要人工处理的变化。它不向 Codex 线程发消息，不恢复或中断线程，也不修改 Codex 的审批设置。

## 启用

按 [部署说明](006-deployment.md)运行 DSH Superagent 后，在面板的 **Codex 观察** 中点 **开始监控**。监控开关保存在 Superagent 的本机数据库中，服务重启后继续生效。**暂停监控** 停止后续扫描，保留已记录的观察和提醒。无需保持 [本机手动试验](009-codex-read-only.md) 的 GUI 开着。

首次扫描列出已索引的主对话、子智能体线程和归档线程，并建立游标；它不会把已有消息当作新提醒。之后约每 30 秒扫描一次，只读取变化线程中新增的用户和助手消息。最多向当前 DSH 模型提供 5000 字符的近期上下文，由模型判断是否需要批准、答复、审阅、解除阻塞或处理失败。普通进展不进入提醒。需要处理的对话显示在 **概览** 和 **Codex 观察**；**关闭提醒** 只改变 Superagent 面板记录。

监控用本机 Codex CLI 的 thread/list、thread/turns/list 和 thread/items/list 只读 RPC。列表枚举非归档和归档记录，沿不透明游标翻页，并显式包含主线程及各类子智能体来源。状态数据库尚未索引的旧记录和不持久化的临时线程可能不在列表中。若增量窗口超过读取上限或游标丢失，面板显示读取异常，不会悄悄标为“已处理”。

## 状态与数据边界

独立启动的 App Server 读取的是**已存储历史**。面板中的更新时间、turn 状态和模型判断可能滞后，不能证明 Codex Desktop 此刻正在运行或等待审批；本功能不提供实时状态。模型分析只接收有界的用户和助手文本，不接收 reasoning、命令输出或文件正文。模型可见的提示和回答保存在 Superagent 私有状态数据库中，供核对；面板接口不返回这些正文。

模型结果是提醒建议，可能判断错误。已确认的提醒保留到人手动关闭；一条后续普通进展不会自动清除尚未处理的提醒。监控不创建 DSH Ticket，也不获得控制 Codex 的权限。
